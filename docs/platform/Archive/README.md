# Platform Documentation Archive

This directory indexes historical documentation; it does not duplicate or move
existing evidence in this adoption commit.

Archived documents explain prior phases, releases, audits, or superseded
designs. They are non-normative. The authoritative specification starts at
`docs/platform/PLATFORM_SPECIFICATION_INDEX.md`.

No documentation was deleted during consolidation. Physical moves and deletion
require a separate review after all inbound links and release references are
verified.
