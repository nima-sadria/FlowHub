مستند فنی API فروشندگان ووکامرس

راهنمای فارسی اتصال به WooCommerce REST API v3 برای مدیریت داده‌های فروشگاه، محصولات، مشتریان، سفارش‌ها و وب‌هوک‌ها.

این مستند بر پایهٔ مرجع رسمی WooCommerce REST API v3 تهیه شده است و مسیرهای آن مربوط به API تاریخی wc-api/v3 هستند.

۱ — پیش‌نیازها و نشانی پایه

WooCommerce ۲.۱ یا جدیدتر، فعال‌بودن REST API و Pretty Permalinks الزامی است.

storeUrl = https://www.your-store.com
apiBase = https://www.your-store.com/wp-json/wc/v3

۲ — الگوی درخواست و پاسخ

بدنه و پاسخ API از JSON استفاده می‌کنند. تاریخ‌ها RFC 3339 در UTC، شناسه‌ها عددی و مبالغ اعشاری به‌صورت رشته با دو رقم اعشار بازگردانده می‌شوند.

۳ — احراز هویت

۳-۱ — HTTPS

Consumer Key و Consumer Secret را با HTTP Basic Auth ارسال کنید.

curl https://www.example.com/wp-json/wc/v3/orders \
  -u consumer_key:consumer_secret

۳-۲ — HTTP

در ارتباط بدون SSL از OAuth 1.0a یک‌طرفه استفاده کنید. پارامترهای oauth_consumer_key، oauth_timestamp، oauth_nonce، oauth_signature و oauth_signature_method الزامی‌اند.

۴ — پارامترها و صفحه‌بندی

GET /orders?status=completed&after=2013-11-01T00:00:00Z&per_page=100&page=1
پارامتر یا هدرکاربرد
filter[limit]تعداد آیتم هر صفحه
pageشمارهٔ صفحه، با شروع از ۱
filter[offset]جابه‌جایی از نخستین منبع
X-WC-Totalتعداد کل منابع
X-WC-TotalPagesتعداد کل صفحه‌ها
Linkنشانی‌های first، prev، next و last

۶ — وب‌هوک‌ها

وب‌هوک‌های فعال، payload JSON را با POST ارسال می‌کنند. برای راستی‌آزمایی درخواست، امضای Base64 شدهٔ HMAC-SHA256 در هدر X-WC-Webhook-Signature را با secret وب‌هوک و بدنهٔ خام مقایسه کنید.

هدرتوضیح
X-WC-Webhook-Topicنمونه: order.updated
X-WC-Webhook-Resourceنوع منبع
X-WC-Webhook-Eventنوع رویداد
X-WC-Webhook-Signatureامضای payload

۷ — عیب‌یابی

  • پیکربندی قدیمی Nginx ممکن است API را دچار اختلال کند.
  • ModSecurity ممکن است POST، PUT و DELETE را مسدود کند.
  • در خطای Consumer key is missing، عبور هدر Authorization را در وب‌سرور یا proxy بررسی کنید.
