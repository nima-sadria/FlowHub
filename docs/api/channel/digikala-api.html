مستند فنی API فروشندگان دیجی‌کالا

راهنمای فارسی اتصال به API فروشندگان دیجی‌کالا برای مدیریت کالا، تنوع، قیمت، موجودی، سفارش، بسته و رخدادها.

این راهنما از مشخصات رسمی OpenAPI دیجی‌کالا تهیه شده است. برای جزئیات هر مسیر و سطح دسترسی، مرجع رسمی را کنترل کنید.

۱ — پیش‌نیازها و نشانی پایه

یک Active Client ثبت‌شده و Scopeهای لازم برای استفاده از API ضروری است.

baseUrl = https://seller.digikala.com/open-api/v1

۲ — دریافت و نوسازی توکن

پس از تأیید دسترسی فروشنده، authorization_code را برای دریافت توکن ارسال کنید.

POST /auth/token
Content-Type: application/json

{ "authorization_code": "CODE_FROM_CALLBACK" }

برای نوسازی، توکن دسترسی منقضی‌شده و Refresh Token را به POST /auth/refresh-token بفرستید و هر دو توکن جدید را ذخیره کنید.

۳ — احراز هویت و Scope

curl 'https://seller.digikala.com/open-api/v1/orders' \
  -H 'Authorization: Bearer ACCESS_TOKEN' \
  -H 'Content-Type: application/json'
مسیرکاربرد
GET /auth/scopesفهرست Scopeهای سرویس
GET /auth/scopes/{client_code}Scopeهای فعال برای Client
POST /auth/revokeلغو دسترسی برنامه

۴ — صفحه‌بندی

در پاسخ‌های فهرستی، اطلاعات صفحه‌بندی در data.pager است. نام پارامترها را برای هر endpoint در Swagger بررسی کنید.

{
  "status": "ok",
  "data": { "pager": { "page": 1, "item_per_page": 50, "total_pages": 4, "total_rows": 183 }, "items": [] }
}

۵ — حوزه‌های اصلی API

حوزهمسیر نمونه

۶ — خطاها و محدودیت درخواست

وضعیتاقدام
400بدنه و خطاهای اعتبارسنجی را اصلاح کنید.
401توکن را نوسازی کنید.
403Scope Client را بررسی کنید.
429با backoff و پس از زمان مجاز تلاش کنید.
500برای عملیات idempotent با backoff دوباره تلاش کنید.
FlowHub — مستندات کانال‌هامرجع رسمی دیجی‌کالا
